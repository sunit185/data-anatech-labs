A modern, premium, enterprise-grade website built for **Anatech Data Labs** — a premier data and AI consulting company helping organizations transform raw data into measurable business value through Analytics, Data Engineering, Automation, and Artificial Intelligence solutions.

- **Design System**: Premium SaaS aesthetic featuring Dark Blue (`#060913`), Vibrant Teal (`#00e5c9`), Sky Blue (`#38bdf8`), and AI Purple (`#a855f7`) with smooth glassmorphism effects and subtle glows.

- **Interactive Booking & Contact System**:

  - Comprehensive contact form with validation, budget/service scoping, and submission feedback.
- **Enterprise Case Studies with Modal Previews**:

  - *FinCorp Advisory*: 80% manual reporting reduction via Power Automate RPA.
  - *LogiTech Logistics*: +35% demand prediction accuracy via Databricks ML models.
- **SEO & Structured Data**: Built-in OpenGraph, Twitter Cards, meta keywords, and Google Schema.org `ProfessionalService` JSON-LD markup.

## 🚀 How to Run Locally

Because the project is built with clean HTML5, Tailwind CSS, Lucide Icons, and Chart.js via official CDNs, **no local `npm install` or node build step is required**.

### Option 1: Direct Browser Launch
Simply double-click `index.html` or open it in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Option 2: Local HTTP Server (VS Code / Python / npx)
- **VS Code**: Right click `index.html` and choose **"Open with Live Server"**.
- **Python**:
  ```bash
  python -m http.server 3000
  ```
  Then visit `http://localhost:3000`.

## 🌐 Instant Deployment

This self-contained directory can be deployed directly to any static web hosting platform:
- **Netlify**: Drag and drop into [app.netlify.com/projects/data-anatech-labs/deploys](https://app.netlify.com/projects/data-anatech-labs/deploys) or [app.netlify.com/drop](https://app.netlify.com/drop)
- **Tiiny Host**: Drag and drop `site.zip` into [tiiny.host](https://tiiny.host)
- **Vercel**: Drag and drop the folder into [vercel.com](https://vercel.com)
- **GitHub Pages**: Push this directory to a GitHub repository and enable Pages in repository settings.
